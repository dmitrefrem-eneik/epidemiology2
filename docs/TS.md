# Техническое задание: База знаний образовательного центра ФБУН ЦНИИ Эпидемиологии Роспотребнадзора

## 1. Общие сведения
**Заказчик:** Образовательный центр ФБУН ЦНИИ Эпидемиологии Роспотребнадзора.
**Цель:** Создание централизованной базы знаний для поддержки образовательного процесса.
**Сроки:** декабрь 2026.

## 2. Основные задачи
- Хранение и систематизация учебно-методических материалов.
- Размещение нормативных документов.
- Поддержка подготовки к аттестациям и экзаменам.
- Хранение шаблонов документов.

## 3. Функциональные требования
- Полнотекстовый поиск (ФБУН, ГЭК, ГИА, ФГОС).
- Версионность документов.
- Разграничение прав доступа (Админ, Контент-менеджер, Преподаватель, Обучающийся).
- Интеграция с Moodle (sdo.crie.ru), Teachbase, ЭИОС, Telegram.

## 4. Архитектура (запрос пользователя)
- Принцип MVC.
- Предварительный дашборд для управления.
- Технологии (из предоставленного транскрипта): PHP, SQLite, Tailwind CSS.
