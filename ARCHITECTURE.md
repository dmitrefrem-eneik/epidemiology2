# Архитектура проекта: База знаний ФБУН ЦНИИ Эпидемиологии

Этот документ описывает архитектуру системы Базы знаний, основанную на паттерне MVC (Model-View-Controller), и план интеграции с существующими платформами.

## 1. Общий обзор
Система предназначена для централизованного хранения, поиска и управления учебно-методическими и нормативными документами.

## 2. Паттерн MVC

### Model (Модели)
- **Document**: Отвечает за метаданные документов (название, тип, версия, статус, ответственный, теги). Хранит пути к файлам.
- **Category**: Управляет иерархией разделов (Нормативная база, Учебно-методические материалы и т.д.).
- **User/Role**: Интеграция с ЭИОС для аутентификации и разграничения прав доступа.

### View (Представления)
- **Dashboard**: Главная панель управления для администраторов и контент-менеджеров.
- **DocumentList**: Интерфейс поиска и фильтрации для пользователей.
- **DocumentDetail**: Просмотр метаданных и истории версий документа.

### Controller (Контроллеры)
- **DashboardController**: Логика отображения статистики и управления контентом.
- **SearchController**: Обработка поисковых запросов и фильтрации.
- **DocumentController**: Управление загрузкой, обновлением версий и архивированием.

## 3. Схема данных (SQLite)
База данных `kb.sqlite` содержит следующие таблицы:
- `documents`: ID, title, type, category_id, version, status, updated_at, responsible_id, file_path.
- `categories`: ID, parent_id, name.
- `audit_log`: История изменений документов.

## 4. Интеграция
- **Moodle (sdo.crie.ru)**: Использование Moodle как основной платформы доставки контента через API и внешние инструменты.
- **ЭИОС**: Синхронизация ролей и авторизация.
- **Telegram/Max**: Бот для уведомлений об обновлениях документов.

## 5. Варианты реализации прототипа

### А. Динамическая версия (PHP + SQLite)
Находится в директории `dashboard/`.
- **Язык**: PHP 8.3
- **БД**: SQLite 3
- **Использование**: Для локальной разработки и серверного развертывания. Поддерживает полноценный MVC.

### Б. Статическая версия (GitHub Pages)
Находится в корне репозитория (`index.html`, `data.json`).
- **Технологии**: HTML5, JavaScript (Vanilla), Tailwind CSS.
- **Использование**: Для мгновенной демонстрации через GitHub Pages. Данные загружаются из JSON-файла.
